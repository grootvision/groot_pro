# نصب ماژول «گزارش کار» در Groot Vision

## ۱) کپی ماژول
پوشه‌ی `work-report` را کنار بقیه‌ی ماژول‌های افزونه بگذارید:

```
groot-vision/
└── modules/
    └── work-report/
        ├── work-report.php        ← فایل اصلی ماژول
        ├── includes/              ← منطق (هر فایل یک مسئولیت)
        └── assets/                ← css / js / chart.umd.js
```

## ۲) تغییر در `groot-vision-tools.php`
هر جا که بقیه‌ی ماژول‌ها لود می‌شوند این چند خط را اضافه کنید
(اگر مسیر پوشه‌ی ماژول‌های شما فرق دارد، فقط مسیر را اصلاح کنید):

```php
// ── ماژول گزارش کار ──
$gvwr_main = __DIR__ . '/modules/work-report/work-report.php';
if ( file_exists( $gvwr_main ) ) {
    require_once $gvwr_main;
}
unset( $gvwr_main );
```

## ۳) تغییر در `admin.php` (کارت در داشبورد افزونه‌ی اصلی)
داخل داشبورد، کنار کارت بقیه‌ی ماژول‌ها:

```php
<?php if ( function_exists( 'gvwr_dashboard_card' ) ) { gvwr_dashboard_card(); } ?>
```

اگر داشبورد شما کارت‌ها را با HTML خودش می‌سازد، این دو را استفاده کنید:
`gvwr_menu_url()` ← آدرس ماژول، و `gvwr_dashboard_card( false )` ← HTML کارت به‌صورت رشته.

> ماژول منوی خودش («گزارش کار») را دارد تا کارمند و مدیر شرکت بدون دسترسی به منوی اصلی افزونه کار کنند.

## ۴) راه‌اندازی (۵ دقیقه)
1. افزونه را یک بار بارگذاری کنید؛ جدول‌ها، نقش‌ها، ۲۲ دسته‌بندی پیش‌فرض (سئو/محتوا/طراحی/فنی) و برگه‌ی کارفرما خودکار ساخته می‌شوند.
2. **گزارش کار ▸ کارمندان و دسترسی** افراد را اضافه کنید: کارمند، مدیر گزارش کار (مدیر شرکت شما)، کارفرما. هر کدام با یوزر وردپرس خودشان وارد می‌شوند.
3. **گزارش کار ▸ تنظیمات**: شورت‌کد `[groot_work_report]` و آدرس برگه‌ی آماده‌ی کارفرما آنجاست.
4. **گزارش کار ▸ کلمات کلیدی**: فهرست کلمات را دستی یا با Excel/CSV وارد کنید (ستون‌ها: کلمه، صفحه‌ی هدف، رتبه‌ی فعلی).

## نقش‌ها
| نقش | چه می‌بیند |
|---|---|
| کارمند | فقط فرم ثبت، «گزارش‌های من»، تقویم و رتبه‌ی کلمات؛ گزارش دیگران را نمی‌بیند |
| مدیر گزارش کار | همه‌ی گزارش‌ها با ریز جزئیات و ساعت‌ها، تأیید/رد، مقایسه، خروجی Excel، تنظیمات |
| کارفرما | فقط برگه‌ی شورت‌کد: بدون نام کارمند و بدون ساعت؛ فقط گزارش‌های تأییدشده (قابل تغییر در تنظیمات) |
| مدیر کل وردپرس | همه‌ی دسترسی‌ها |

## کجا چه چیزی را ویرایش کنم؟
| می‌خواهم… | فایل |
|---|---|
| ظاهر فرم ثبت یا لیست گزارش‌ها | `includes/views.php` |
| داشبورد مدیر، مقایسه، تقویم | `includes/views-manager.php` |
| صفحه‌ی کلمات کلیدی | `includes/views-keywords.php` |
| ظاهر گزارش کارفرما | `includes/client.php` |
| فیلد جدید در گزارش | `db.php` (ستون) ← `data.php` (`gvwr_clean_item`) ← `views.php` (`gvwr_row_html`) |
| رنگ و فونت | بالای `assets/css/wr.css` (متغیرهای `--brand` و …) |
| تنظیم جدید | `helpers.php` (`gvwr_defaults`) ← `views-admin.php` |

## نکات
- **PDF**: دکمه‌ی «دریافت PDF» پنجره‌ی چاپ مرورگر را باز می‌کند؛ مقصد را «Save as PDF» بگذارید (قالب چاپ آماده است).
- **اسکرین‌شات**: دکمه‌ی 📷 یا چسباندن تصویر با Ctrl+V داخل ردیف؛ تصاویر در کتابخانه‌ی رسانه ذخیره می‌شوند.
- **فونت**: اگر Vazirmatn روی سایت لود می‌شود خودکار استفاده می‌شود؛ وگرنه Tahoma.
- **Chart.js** نسخه‌ی 4.4.4 داخل ماژول است و به اینترنت/CDN نیاز ندارد.


## انتقال داده‌ی بخش قدیمی «گزارش عملکرد سئو»
- بعد از به‌روزرسانی، در اولین ورود مدیر به پیشخوان انتقال خودکار انجام می‌شود (بدون تکرار؛ اگر دوباره اجرا شود چیزی دوبل نمی‌شود).
- گزارش‌های منتشرشده → «تأییدشده»؛ پیش‌نویس‌ها → «در انتظار تأیید» (به مشتری نمی‌رسند).
- کارمندان قدیمی کاربر وردپرس می‌شوند و رمزشان حفظ می‌شود (وردپرس ۶٫۸+)؛ مشتریان نقش «کارفرما» می‌گیرند.
- جدول‌های قدیمی تا زمانی که در «گزارش کار ← تنظیمات» دکمه‌ی «پاک‌سازی نهایی» را نزنید باقی می‌مانند.
